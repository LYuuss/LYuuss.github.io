QChain

Python · Flask · Docker

J’ai développé une blockchain Proof of Work en Python pour étudier la synchronisation entre nœuds et le maintien d’un état commun. Le projet combine transactions signées, mempool et stockage persistant.

Une API REST, une CLI et un testnet Docker à trois nœuds permettent d’exécuter et de tester le réseau. La gestion des forks repose sur le travail cumulé, avec des tests automatisés pour vérifier le comportement du système.

Algorithmique des graphes

Route Planning

C · Dijkstra · CSR · Tas binaire

Un moteur de calcul d’itinéraires en C. L’algorithme de Dijkstra, associé à un tas binaire, recherche le plus court chemin dans un graphe routier pondéré.

Le graphe utilise une représentation compacte CSR pour limiter l’espace mémoire. Le projet gère également les identifiants des sommets et l’indexation des noms de rues.
