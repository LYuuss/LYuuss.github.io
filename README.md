# Lyes Djemaa — bilingual CV website

A lightweight static site in French and English

## Content and files

- `content.json`: the French and English text.
- `generate.py`: generates both HTML pages from the shared layout.
- `dist/index.html`: French version.
- `dist/en/index.html`: English version.
- `dist/assets/style.css`: shared responsive design, light/dark themes and print styles.
- `dist/assets/script.js`: theme preference, print action and language anchor preservation.
- `dist/assets/CV_Lyes_D_Stage.pdf` and `CV_Lyes_D_Internship.pdf`: existing CV downloads.



## Content sources

The previous September 2026 portfolio and the latest available French and English CVs. Downloaded PDFs are preserved as supplied; they may reflect different CV revision dates.
